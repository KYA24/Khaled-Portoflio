# Achievement Images

Save the achievement images with these filenames:

- `unithon-global.jpg` - global Unithon win photo with the prince
- `mihbara-local.jpg` - local Arabic hackathon win photo/certificate
- `halla-booth.jpg` - Halla workspace or booth photo used for the CodeLab incubation achievement

The site reads these paths from `data/achievements.json`.
